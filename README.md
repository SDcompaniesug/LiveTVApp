# Live TV Android App

Native Java + XML Android live TV starter app.

Features:
- Professional dark live-TV interface
- Channel list
- Full-screen Media3 player
- HLS/M3U8 playback
- Landscape player
- Internet permission
- Easy channel URL replacement

Build with JDK 17 and Gradle 8.9:
`gradle assembleDebug`

Replace the sample streams with channels you have permission to distribute. These are demo streams, not a bundled channel subscription.
